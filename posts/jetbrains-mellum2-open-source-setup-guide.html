Why This Matters

The AI coding assistant landscape just shifted dramatically. JetBrains has officially open-sourced Mellum2, their advanced code-completion and testing model, creating new possibilities for developers who've hit walls with existing tools like Claude Code, GitHub Copilot, and Cursor. The core problem: Enterprise teams and security-conscious organizations face a difficult choice. Cloud-based AI assistants like Claude Code deliver impressive capabilities but require sending proprietary code to external servers. For companies in regulated industries—healthcare, finance, defense—this isn't just inconvenient; it's often prohibited by compliance requirements. Even when allowed, intellectual property concerns make CTOs nervous about training data policies. Where Claude Code can't go:

  • Air-gapped development environments
  • Classified or defense-related projects
  • Healthcare systems bound by strict HIPAA data residency rules
  • Financial institutions with code escrow requirements
  • Any organization with "no external code transmission" policies

    • Mellum2 addresses these constraints directly. As a fully open-source, locally-deployable model, it runs entirely within your infrastructure. No code leaves your network. No API calls to external services. Complete data sovereignty while maintaining competitive code completion, test generation, and security analysis capabilities.

    This guide walks you through deploying Mellum2 in your environment, configuring it for optimal performance, and integrating it with your existing JetBrains IDE workflow for AI-assisted software testing and security analysis.

    Prerequisites

    Before starting, ensure you have: Hardware Requirements:

  • Minimum: 32GB RAM, NVIDIA GPU with 12GB VRAM (RTX 4080 or equivalent)
  • Recommended: 64GB RAM, NVIDIA GPU with 24GB+ VRAM (RTX 4090, A100, H100)
  • Enterprise: Multi-GPU server configuration for team deployments
    • Software Requirements:
  • Docker 24.0+ with NVIDIA Container Toolkit
  • JetBrains IDE (IntelliJ IDEA 2026.1+, PyCharm 2026.1+, or WebStorm 2026.1+)
  • Python 3.11+ (for custom integrations)
  • Git 2.40+
    • Accounts & Access:
  • JetBrains Account (free tier sufficient)
  • Access to JetBrains Mellum2 repository on GitHub
    • Network Configuration:
  • Ports 8080 and 8443 available for local model server
  • No external network access required post-installation

    • Step-by-Step Instructions

    Step 1: Clone the Mellum2 Repository

    Start by obtaining the open-source Mellum2 codebase from JetBrains' official GitHub repository. 

    Create a dedicated directory for Mellum2
    
mkdir -p ~/ai-tools/mellum2
cd ~/ai-tools/mellum2


    Clone the repository
    
git clone https://github.com/JetBrains/mellum2.git .


    Verify the clone
    
ls -la

    Expected output: Dockerfile, docker-compose.yml, models/, src/, configs/

    Step 2: Download Model Weights

    Mellum2 ships with multiple model variants. For security-focused development, we recommend the mellum2-secure-7b variant, which includes enhanced training on vulnerability detection patterns. 

    Navigate to the models directory
    
cd models


    Run the download script (approximately 14GB download)
    
./download-weights.sh --variant secure-7b --quantization q4_k_m


    Verify integrity
    
sha256sum -c checksums.sha256

    aria2c can significantly speed up the download process if you're on a high-bandwidth connection: 

    Alternative: parallel download with aria2
    
aria2c -x 16 -s 16 \
  https://releases.jetbrains.com/mellum2/weights/secure-7b-q4_k_m.gguf

    Step 4: Build and Launch the Mellum2 Server

    Return to project root
    
cd ~/ai-tools/mellum2


    Build the container
    
docker compose build --no-cache


    Launch in detached mode
    
docker compose up -d


    Verify the server is running
    
curl -s http://localhost:8080/health | jq .

    Expected response: 

    {
  "status": "healthy",
  "model": "mellum2-secure-7b",
  "version": "2.1.0",
  "gpu_memory_used": "11.2GB",
  "ready": true
}

    Step 5: Install the JetBrains IDE Plugin

    Open your JetBrains IDE and install the official Mellum2 plugin.

  • Navigate to File → Settings → Plugins (or Preferences on macOS)
  • Click Marketplace tab
  • Search for "Mellum2 Local Assistant"
  • Click Install and restart the IDE

    • Step 6: Configure Plugin Connection

    After restarting, configure the plugin to connect to your local Mellum2 server:

  • Open Settings → Tools → Mellum2
  • Set Server URL to http://localhost:8080
  • Enable Security Analysis Mode
  • Set Test Generation Framework to match your project (JUnit 5, pytest, Jest, etc.)
    •
